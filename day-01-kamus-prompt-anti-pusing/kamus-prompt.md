# 🎁 Kamus 15 Prompt Sakti & Template Otomasi Harian (Day 1)

Kompilasi 15 template prompt pilihan untuk membebaskan waktu kerja dari rutinitas repetitif. Disusun dengan prinsip keterbukaan, anti-halusinasi, dan format eksekusi instan.

---

## 📌 Track 1: Produktivitas & Awam (Yuk Pakai AI)

### 1. Merapikan Notulensi Rapat Berantakan
```text
Bertindaklah sebagai sekretaris eksekutif profesional. Berikut adalah coretan kasar dan rekaman suara dari rapat internal tim kami:
[TEMPELKAN CATATAN KASAR DI SINI]

Tolong ubah menjadi notulensi rapi dengan struktur:
1. Ringkasan Eksekutif (maksimal 3 kalimat).
2. Keputusan yang Telah Disepakati (bullet point).
3. Action Items (tabel berisi kolom: Tugas, PIC / Penanggung Jawab, Deadline, Status Awal).
Gunakan bahasa Indonesia formal namun ringkas.
```

### 2. Intisari Laporan Dokumen PDF Panjang
```text
Analisis teks laporan berikut. Berikan intisari dalam format:
1. 3 Temuan Utama yang paling mengejutkan atau paling krusial.
2. Apa risiko operasional/finansial terbesar yang disebutkan dalam dokumen ini.
3. 5 rekomendasi tindakan segera untuk tim manajemen.
Hindari jargon teknis yang tidak perlu, fokus pada dampak nyata.

[TEMPELKAN TEKS LAPORAN DI SINI]
```

### 3. Penata Jadwal Kerja Harian (Time Blocking Matrix)
```text
Saya memiliki daftar tugas kerja hari ini dengan estimasi waktu dan urgensi:
[DAFTAR TUGAS]

Tolong susun jadwal kerja terstruktur (time blocking) dari jam 09.00 - 17.00 WIB dengan aturan:
- Pekerjaan berpikir berat di pagi hari (Deep Work).
- Rapat dan administrasi di siang hari setelah makan siang.
- Sediakan jeda istirahat 10 menit setiap 50 menit kerja (teknik Pomodoro).
```

### 4. Draf Klarifikasi Email Santun Namun Tegas
```text
Bantu saya membalas email dari rekan kerja/klien yang meminta perubahan ruang lingkup (scope creep) di luar perjanjian awal:
[TEMPELKAN EMAIL MEREKA]

Kriteria balasan:
- Nada bahasa sangat profesional, hangat, dan tidak konfrontatif.
- Mengapresiasi ide mereka, namun menegaskan bahwa perubahan ini membutuhkan penyesuaian anggaran dan timeline baru.
- Berikan pilihan jadwal diskusi 15 menit untuk membahas addendum kontrak.
```

### 5. Pengubah Catatan Voice Note Acak Menjadi SOP Ringkas
```text
Berikut transkrip suara instruksi kerja yang saya rekam saat di jalan:
"[TRANSKRIP VOICE NOTE]"

Ubah instruksi ini menjadi SOP (Standar Operasional Prosedur) 1 halaman dengan:
1. Tujuan Prosedur.
2. Alat/Aplikasi yang Dibutuhkan.
3. Langkah-demi-Langkah Berurutan (Checklist).
4. Kriteria Keberhasilan (Definition of Done).
```

## 🏢 Track 2: Bisnis, Toko Online & UMKM (Yuk Otomasi)

### 6. System Prompt CS Toko Online Ramah & Anti-Halusinasi
```text
Anda adalah "SuruhBot", asisten customer service ramah dan profesional dari [NAMA BRAND].
Tugas utama Anda adalah membantu calon pembeli menjawab pertanyaan seputar katalog produk, jam buka, dan proses pengiriman.

PANDUAN KETAT:
1. HANYA jawab berdasarkan informasi katalog berikut:
[TEMPELKAN DAFTAR PRODUK, HARGA, & STOK DI SINI]
2. Jika pelanggan bertanya hal di luar katalog (misal: diskon khusus yang tidak tercantum, atau topik politik/pribadi), jawab dengan sopan: "Mohon maaf kak, untuk informasi tersebut belum tersedia di sistem kami. Kakak bisa menghubungi admin manusia kami di jam 09.00 - 17.00 WIB."
3. JANGAN PERNAH mengarang harga, estimasi waktu kirim yang tidak pasti, atau janji diskon tanpa dasar.
4. Gunakan gaya bahasa kasual ramah khas Indonesia (panggil pelanggan dengan sapaan "Kak").
```

### 7. Membalas Komplain Pelanggan yang Marah
```text
Saya seorang pemilik bisnis yang menerima komplain berikut dari pelanggan:
"[TEMPELKAN PESAN KOMPLAIN DI SINI]"

Situasi sebenarnya di internal: [JELASKAN KENDALA INTERNAL SECARA SINGKAT].
Tolong buatkan draf balasan dengan kriteria:
- Nada empati, tenang, dan tidak defensif.
- Mengakui kendala tanpa menyalahkan pihak luar / kurir.
- Memberikan solusi konkret atau kompensasi bertahap: [SEBUTKAN OPSI SOLUSI].
- Panjang pesan maksimal 3 paragraf pendek.
```

### 8. Analisis Sentimen & Feedback Review Pembeli
```text
Berikut adalah 20 ulasan produk terbaru dari toko kami:
[TEMPELKAN ULASAN PEMBELI]

Ekstraksi analisis ini menjadi:
1. Apa 3 hal yang paling disukai pembeli (Kelebihan Utama).
2. Apa 3 keluhan paling sering muncul (Pain Points).
3. Tabel perbaikan prioritas: Masalah, Dampak ke Penjualan, Rekomendasi Aksi Cepat.
```

### 9. Formula Rumus Otomatis Google Sheets Tanpa Hafal Rumus
```text
Saya mengelola Google Sheets dengan kolom:
A: Tanggal Transaksi, B: Nama Pembeli, C: Kategori Produk, D: Jumlah, E: Harga Satuan, F: Status Pembayaran (Lunas/Pending)

Tolong buatkan formula Google Sheets untuk:
1. Menghitung total omset yang statusnya 'Lunas' untuk kategori 'Elektronik' pada bulan berjalan.
2. Tampilkan formula QUERY atau FILTER yang bisa saya salin langsung ke sel G2.
3. Jelaskan cara kerjanya dalam 2 kalimat sederhana.
```

### 10. Draf Penawaran Kolaborasi / Sponsorship B2B
```text
Saya ingin menawarkan proposal kerjasama antara [BISNIS SAYA] dan [PERUSAHAAN TARGET].
Nilai unik kami: [SEBUTKAN AUDIENS/TRAKSI].
Manfaat untuk mereka: [SEBUTKAN KEUNTUNGAN MITRA].

Buatkan draf surat penawaran resmi maksimal 250 kata yang fokus pada mutual benefit, ROI, dan call to action untuk jadwal call 15 menit.
```

## 💻 Track 3: Software Engineer (Yuk Bikin AI)

### 11. Deteksi Edge-Case & Concurrency Bug (Production Grade)
```text
Tinjau potongan kode berikut dengan standar production-grade:
[TEMPELKAN FUNGSI / GOROUTINE KODE]

Lakukan analisis mendalam terhadap:
1. Potensi race condition, goroutine leak, atau memory unbounded growth.
2. Error handling yang tertelan secara diam-diam (silent error swallowing).
3. Perilaku kode saat menerima payload kosong, null, atau malformed.
Berikan saran refaktor minimalis beserta contoh unit test table-driven.
```

### 12. Ekstraksi Chat Transaksi ke Strict JSON (Constrained Decoding)
```text
Ekstraksi data transaksi dari percakapan pelanggan berikut:
"[PESAN CHAT PELANGGAN]"

Keluarkan output HANYA dalam format JSON valid tanpa tanda markdown (tanpa ```json) dan tanpa teks pengantar apapun.
Schema JSON yang wajib ditaati:
{
  "customer_name": "string",
  "product_code": "string",
  "quantity": number,
  "payment_method": "COD | TRANSFER | QRIS | UNKNOWN",
  "notes": "string | null",
  "confidence_score": number
}
```

### 13. Generator Migration Schema & Indeks Database
```text
Berdasarkan kebutuhan entitas berikut:
[JELASKAN ENTITAS DAN KEBUTUHAN QUERY]

Buatkan DDL SQL (PostgreSQL / SQLite) yang memenuhi:
1. Normalisasi 3NF.
2. Tipe data efisien (misal UUID / ULID vs BIGINT).
3. Foreign key constraint ON DELETE CASCADE / RESTRICT yang tepat.
4. Composite index untuk optimasi kueri yang paling sering dibaca.
```

### 14. Pembuat Test Case Boundary & Malicious Input (Security Fuzzing)
```text
Berikut endpoint API handler kami:
[TEMPELKAN KODE HANDLER]

Rancang 10 skenario pengujian fuzzing dan batas nilai (boundary testing):
- SQL injection / prompt injection payload.
- Unicode overflows / null byte injections.
- Large payload denial-of-service test.
Tuliskan test case ini dalam format format framework testing standar.
```

### 15. Refaktor Kode Menjadi Arsitektur SOLID & Clean Architecture
```text
Potongan kode berikut terlalu panjang dan memiliki coupling yang erat:
[TEMPELKAN KODE]

Refaktor kode ini dengan memisahkan:
1. Domain Entity & Business Rules (murni tanpa dependensi I/O).
2. Repository Interface / Port.
3. Infrastructure Adapter.
Gunakan Dependency Injection agar mudah di-unit test dengan mock repository.
```
