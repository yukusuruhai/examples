# Modul 03: Anatomi MCP untuk Awam (Host, Client, Server) 🌱

Memahami mengapa prompt panjang saja tidak cukup tanpa jalur koneksi data yang terstruktur.

## 3 Komponen Utama MCP
- **MCP Host**: Aplikasi tempat kita mengetik perintah (misal Claude Desktop, Cursor, atau bot lokal).
- **MCP Client**: Penghubung di dalam Host yang menerjemahkan permintaan AI menjadi panggilan tool standar.
- **MCP Server**: Program kecil di laptop kita yang menjaga pintu folder/spreadsheet dan hanya memberikan data yang diizinkan.

Lihat `cheatsheet-anatomi-mcp.md` untuk panduan lengkapnya 🌱
