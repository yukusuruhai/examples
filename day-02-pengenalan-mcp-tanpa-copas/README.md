# Modul 02: Stop Copy-Paste ke ChatGPT — Konfigurasi Dasar MCP Lokal 🌱

> Menghubungkan AI langsung ke folder kerja di laptop sendiri dengan izin baca yang terkontrol.

## Apa Isi Folder Ini?
1. `claude_desktop_config.example.json` — Contoh konfigurasi resmi Model Context Protocol (MCP) untuk membaca folder kerja lokal.
2. `prompt-uji-koneksi.md` — 3 perintah pertama untuk menguji apakah AI sudah bisa membaca berkas lokalmu tanpa upload manual.

## Cara Pakai Singkat
1. Salin isi `claude_desktop_config.example.json` ke pengaturan MCP di aplikasi AI desktopmu (Claude Desktop / Cursor / Cline).
2. Ganti `/home/username/dokumen-kerja` dengan lokasi folder yang ingin kamu izinkan.
3. Gunakan kalimat di `prompt-uji-koneksi.md` untuk mulai bekerja dengan tenang 🌱
