# Otomasi Notulensi Rapat & Action Items (Day 8)

Solusi untuk menghentikan kebiasaan menyalin catatan rapat yang berantakan ke lembar kerja berulang kali.

## Isi Folder:
1. `prompt-notulensi.md`: Template prompt lengkap yang bisa langsung disalin ke ChatGPT, Claude, atau Gemini.
2. `extract_meeting_notes.py`: Skrip CLI Python untuk memproses file catatan rapat lokal.

## Cara Menggunakan Skrip:
```bash
# Menjalankan demonstrasi langsung
python extract_meeting_notes.py

# Atau proses file catatan rapat sendiri
python extract_meeting_notes.py catatan_rapat.txt
```
